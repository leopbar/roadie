# Console web (Next.js)

Interface da equipe: login, simulador de atendimento com painel de bastidores,
histórico de conversas, tickets, qualidade de dados, políticas, catálogo e
configurações. A documentação completa está no README da raiz.

Desenvolvimento fora do Docker:

```bash
cp .env.local.example .env.local   # aponta /api para a porta local da API
npm install
npm run dev
```
